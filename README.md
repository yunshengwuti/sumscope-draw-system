# 森浦 Lucky Draw

一个基于浏览器的星盘抽奖工具，无需安装，打开即用。

## 功能

- 导入 Excel 名单（.xlsx / .xls），自动识别姓名、QB账号、机构列
- 自定义奖项（一等奖、二等奖、三等奖），设置每项人数
- 点击星盘触发动画抽奖，按奖项顺序依次抽取
- 导出抽奖结果为 CSV
- 纯前端实现，无需服务器，数据不上传

## 使用方法

1. 打开网页（或本地直接双击 `index.html`）
2. 点击「抽奖设置」，上传 Excel 名单并配置奖项
3. 点击确认后，点击主页面星盘开始抽奖
4. 抽完后可在「抽奖结果」查看并导出

## 技术栈

- 纯 HTML5 + Vanilla JavaScript + Canvas API
- 无框架依赖，单文件即可运行
- 使用 [SheetJS](https://sheetjs.com/) 解析 Excel 文件
